Set up bukmark

  1. Enter your bukmark server's address under Server below and log in. No server yet? Install one with Docker.
  2. Pin bukmark capture to the toolbar from your browser's extensions menu.
  3. On any page, click the bukmark button to save it, or press .

Defaults to http://localhost:3000, matching docker compose up -d. Point it anywhere — the browser will ask permission for that address the first time you save it.

Saving a page sends its address and title to this server, and nowhere else. Opening the popup on a page sends its address there too, to show whether it is already saved.

Create one in the web app under Settings › Access tokens. It is sent only to the server above, and Log out revokes it.

Import browser bookmarks

Every bookmark is imported unsorted. The folder it was in is kept as a hint for sorting later, but nothing is filed automatically. Safe to run more than once — existing links are not duplicated and previously deleted ones stay deleted.

Import sends every bookmark's address, title and folder to your server. Your browser first asks to let the extension read your bookmarks.

Log in to import.

Import browser bookmarks

This browser doesn't let extensions read bookmarks. Export them to an HTML file (in Safari: File › Export › Bookmarks), then import that file in the web app under Settings › Import bookmarks.
